# Seven-minute demo

| Time | Action | Evidence |
| --- | --- | --- |
| 00:00–01:00 | Start the isolated console and open Overview | Explain Proposal, Admission, Effect, Receipt and Recovery. |
| 01:00–02:00 | Run stale token scenario | In Timeline open result_withheld, then follow the accepted key to the published bytes. |
| 02:00–03:00 | Run idempotency scenario | Compare the first accepted publication and the conflict record. Inspect the retained receipt. |
| 03:00–04:30 | Run crash recovery | Show the worker exit checkpoint, receiver confirmation and recorded replay decision. |
| 04:30–05:30 | Compare two Runs | Examine attempts, events and results side by side. Optionally run UNKNOWN from Workspace and show its unavailable receipt. |
| 05:30–06:30 | Open Research and select violations | Show 27 final matches, four historical violations and the strong-control comparison. |
| 06:30–07:00 | Run Re-Audit and export a cell | Inspect the target row, frozen protocol SHA, archive commit and raw files. |

The browser smoke script exercises the primary offline demo path and produces screenshots. If verification fails, open the persisted audit failure or the original event and report what was observed. The cancellation extension shows process exit and local slot release when recorded.
