# 复现分级

把代码放到 GitHub 只覆盖仓库本身。一次 EpochGate 2.0 运行要能回答三个不同的问题。

## R1 环境

固定 `base_commit` 和 `change_commit` 的完整 SHA、容器镜像 digest、DSH `0.2.2-rc.1`、插件锁文件和 Python 锁文件。任务在 Linux 容器里执行。Windows 工作区只做不评分的插件单测。仓库文件和脚本使用 LF。

## R2 轨迹

保存 Session 事件前缀哈希、工具参数和结果哈希、`evidence_read_set`、工作区快照哈希、未提交 diff，以及模型原始响应。响应里记录 `model_alias`、`reported_model`、调用日期、thinking、effort、token usage 和错误类型。

Trace Replay 使用这些响应重放评分。它不构成一次新的模型采样。

## R3 统计

评分器、切分和统计脚本在读取留出结果之前冻结。主单位是基础任务根。失败保留在分母里。重算脚本读冻结后的事件，不重新调用 API。

## 审计命令

```powershell
python -m uv run python scripts/audit_checkpoint.py results/semantic-state/checkpoints.jsonl
python -m uv run python scripts/audit_gold_leakage.py results/semantic-state/agent_view.json
python -m uv run python scripts/audit_reproducibility.py results/semantic-state/run_manifest.json
```

三个脚本在没有真实运行文件时，可以用内置样例自检。它们不证明已经有五个事件对，也不证明 Agent 已经跑通。
