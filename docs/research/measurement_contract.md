# 测量合同

写于任何确认性结果之前。读取留出结果之前，主比较和安全容忍界限不再改。

## 主比较

失效或相关更新条件下，LLM Dependency 相对 Re-read and Retest，以及相对 Static Dependency。两条都报。Global Reset 单独作为保守对照，不作为主要创新比较。

诊断臂是“不处理更新”。它只解释过期证据的风险。

## 同时报告的量

任务成功率、过期证据误用、该刷新却没刷新、无关更新却重做、仍有效不变量是否保持、Candidate Invalid Attempt、Gateway Rejection、Final Task Failure、相对 Clean 的额外 token、工具次数、延迟、成本和 wall time。

LLM Dependency 为了判断依赖而多出来的模型调用计入成本。Re-read and Retest 多出来的工具调用也计入。不只统计最后一次生成。

成功率下降而 token 下降，写成权衡，不写成策略整体更好。安全非劣效没有被证明时，只报告观察到的差。

## 失败

超时、限流、工具异常和未完成 episode 保留在分母里。不因为结果不显著而改用诊断臂当主结果。只有一轮模型调用时，完成时间不叫 workflow 完成时间。

## 预算

每次运行冻结最大步骤、token、工具次数、成本上限和 wall time。上下文压缩发生时记一条事件，不把它当成模型主动刷新证据。

## 两种复现

Trace Replay 重放已经保存的模型响应，用来核对环境、策略、评分和事件。它不是新的独立样本。

Fresh API Rerun 重新调用 API，用来估计采样是否稳定。论文里两种运行分列。

## 统计单位

先在基础任务根内配对，再对任务根做区间估计。同一仓库的多个任务根另做聚类敏感性。仓库留出不存在时，不写跨仓库泛化。
