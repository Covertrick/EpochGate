## 统计

`scripts/v2_score.py` 的输出在 `results/runtime/correctness/v2-m6/summary.json`。

Coding 确认的未阻塞 S1 配对少于 8。精度状态是 `PRECISION_NOT_MET`。预算不允许再加任务。

## 验收

四条里，独立评分、同一补丁的四臂对照、blocked 的原文或轨迹标签，在本轮新格子上成立。运行器当时不在记录所写的 Git SHA 里，这一条不成立。因此不写 `GO_EXTENSION`，也不再扩大样本。

投稿口径：

- 可以写的是机制观察。履约家族里，通知送达时 B1 比 B2 更多次接纳过期凭证，但样本内没有方差，精确区间半宽超过 0.25。Coding 的少数未阻塞格子里，S1 上 B0/B1 接纳了过期补丁而 B2/B3 没有，隐藏测试没有通过；一组 S3 上只有 B3 恢复了已授权字节。
- 不可以写成总体精度、编码任务可靠性、LangGraph 的完整编码迁移，或 Full 优于一个已经具备原子提交的外部系统。
- 历史 GO 保留为当时规则下的同家族结论。零宽 bootstrap 不进入跨任务主张。冻结稿本轮不改。
