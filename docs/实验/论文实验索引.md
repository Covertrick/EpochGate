## 找数据

- v3 正式隐藏测试读 `results/runtime/correctness/v3-coding/rescore/summary.json`。确认分母是 4，含 `code-click-ac0e297e` 的 `BUDGET_EXCEEDED`。原始 trace 里的 `docker_unavailable` 保留。
- v3 五个补丁和 trace 不改。归档哈希在 `results/runtime/correctness/v3-coding/artifact/` 与 `freeze.json`。
- E4 模型格读 `results/runtime/correctness/after/e4` 和 `results/runtime/correctness/e4-repeat`。容器评分读 `results/runtime/correctness/e4-audit/container_measurements.json`。旧 360 与新 120 不相加。
- v4 与 v3、E4、M4 都不相加。v4 开发集分母是三个任务，失败格留在 `dev/gate.json`。
- 补丁应用成功不是任务完成。隐藏测试、过时接纳、后继完成分开看。
- `results/paper/artifact-manifest.json` 写明哪些内容不能重建。

三个入口不能混用：

- `python scripts/verify_offline.py`：不调用模型，核对已经落盘的 JSON。
- `python -m uv run python scripts/verify_container.py`：用固定镜像重跑冻结补丁。这不是在线复现。
- `python -m uv run python scripts/run_model_evaluation.py`：没有 API key 就停止。有 key 时才生成 v4 轨迹。

## 不支持的说法

没有验证 GPU 回收，不支持任意 HTTP exactly-once，没有测掉电，没有证明跨任务普遍提升，没有首次提出 stale 不等于 unsafe，也没有首次提出任务结果不同于可验证证据。
