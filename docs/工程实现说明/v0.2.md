## 1. 目录

## 2. 依赖方向

```text
cli / examples / tests / experiment
        ↓
     runtime
    ↙  ↓  ↘
scheduler  gateway  registry / observation / events / refresh_pool
    ↓         ↓
  models   EnvironmentAdapter / InferenceBackend
```

必须守住：

1. `scheduler.py` 不得 import gateway、environment、backend 的具体实现。
2. `scheduler.decide` 只接收裁剪后的 `SchedulerSnapshot`，不持有仓库或 evaluator。快照里的观测没有 payload。
3. 只有 `gateway.py` 可以调用 `environment.commit`。
4. `scheduler.py` 和 `runtime.py` 的源码里不写具体工具名。配方来自环境的 `default_refresh()`，动作类型来自模型工具调用或后端返回的候选。运行时按 `ToolSpec.role`（`read` 或 `effect`）分发。
5. 时间用 `time.monotonic()`。
6. 运行依赖：pydantic、typer、httpx。开发再加 pytest、pytest-asyncio。Python `>=3.12`。

公开函数的说明使用中文四段：输入、输出、副作用、失败。

## 3. 运行时在做什么

`Runtime.run` 对已登记任务循环：

1. `changes(cursor)`。新事件把来源标成 dirty，不把环境真值放进快照。
2. 丢掉未在途且已过期的租约，记下 `lease_expired`，下一轮重新准入。
3. 调度器只看快照。可以给出 `refresh`、`admit`、`dispatch`、`wait`、`finish`、`timeout`、`cancel`。
4. 刷新走 `RefreshPool`，只调用 `observe`。
5. 派发占一个槽，直到 `max_inflight`。没有槽时 `decision_wait` 的 `reason` 写明在等的任务，以及当前占槽的任务。
6. 模型若返回读工具，把观测正文追加进该 attempt 的会话再请求；若返回写工具，才变成 `CandidateAction` 交给网关。`InferenceRequest.context` 带观测正文，不只是 id。
7. 网关拒绝里如果是 stale、版本冲突、租约过期或尝试已无资格，且截止时间还在，就新开 attempt，不把任务打成终态。库存不足仍是 `rejected`。
8. 截止时间已过且没有成功提交，记 `timed_out`。已提交的尝试仍记成功。
9. 取消分成 `cancel_requested` 和 `cancel_acknowledged`。回执原文写入 `reason`，不表示计算已经停止。

默认 `HappyPathScheduler` 不看 dirty、不发取消。`FcfsEnqueueScheduler`（B0）只在入队时观察一次，之后按到达顺序派发。`RuleScheduler` 在无观测或 dirty 时刷新，有槽时按最早截止再按到达派发，在途且 dirty 且后端声明可取消时发 `cancel`。没有实现设计文档第 9 节的概率打分。

## 4. 怎么跑

在仓库根目录：

```powershell
python -m uv sync --extra dev
python -m uv run pytest -q
python -m uv run epochgate demo
python -m uv run epochgate experiment --seed 1 --out traces
python -m uv run python examples/fake_dynamic_env.py
```

本机没有把 `uv` 放进 PATH 时，用 `python -m uv`。`traces/` 是本地输出，不入库。

`pytest` 不访问外网。HTTP 测试在本机起一个假的 chat completions 服务。

真实端点：

```powershell
$env:EPOCHGATE_BASE_URL = "https://example.test/v1"
$env:EPOCHGATE_API_KEY = "<key>"
$env:EPOCHGATE_MODEL = "<model>"
python -m uv run epochgate http-smoke
```

三个变量缺任何一个，命令以状态码 2 退出，并说明缺哪一项。成功时打印一次工具名和参数。

同一种子再跑一次 B0，事件的类型、原因和任务 id 序列一致。绝对时间戳可以不同。指标函数 `score_trace` 只读 JSONL。

## 5. 换后端或环境

实现 `EnvironmentAdapter` 和 `InferenceBackend`，传给 `Runtime(environment=..., backend=...)`。需要对照实验时再传入 `FcfsEnqueueScheduler` 或 `RuleScheduler`。不必改 `scheduler.py` 或 `runtime.py`。

环境自己公布 `tool_catalog()`、`default_refresh()` 和 `changes(cursor)`。库存示例是 `InventoryEnvironment`：`observe` 只读，`commit` 按来源版本扣减，外生计划由 `plan_exogenous(seed)` 生成。世界不因推理暂停。

`HttpToolBackend` 只解析响应里的第一条 `tool_calls`。`trust_env=False` 时不走进程里的 HTTP 代理，本机假服务需要这样调用。
