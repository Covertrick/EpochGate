# EpochGate 项目开发文档 2.2

日期：2026-11-02。本文是实验平台和论文证据的路线，不是已经测完的结论。v1.3 P0 只订正了旧数字的口径和取消语义，没有新的真实 API 数据。

## 1. 已经核对过的口径

F1 主结果是三个预先指定单元里、双臂都触发的 5 个配对的等权均值：撤销后文本差 465.2 词元，Runtime 本地槽位差 3.6981 秒。`mid_mid` seed 5451 因 A 臂 `trigger_late` 未纳入。三个单元再等权是 425.1667 词元和 3.3761 秒。没有做过 Holm、t 检验或 Wilcoxon。`response.aclose()` 只表示本地停止读取。详见 [v1.3-证据闭环.md](../测试记录/v1.3-证据闭环.md)。

以后每一张主表都要能回答：用了哪些原始行、排除了哪些行、为什么排除、统计单位是什么。整体效应按预先分配的全部配对计算。条件效应只在双臂都触发的配对上计算，并且单独标出。

## 2. 还要回答的四个问题

1. 普通本地断流能解释多少收益。
2. 只有前提失败才撤销，是否比“一有信号就断流”少误取消、少接受旧结果。
3. 队列等待的改善是不是只出现在 FIFO。
4. 停掉旧 attempt 之后，原任务恢复完成率是否掉过预先写死的 10 个百分点。

B 和 C 如果在同一时刻关闭本地读，槽位时间可以相同。那表示断流速度没有额外收益，贡献在资格判断。

## 3. 对照

| 臂 | 规则 |
| --- | --- |
| A | 前提失败才撤销资格，本地继续读，旧结果由 Gateway 隔离 |
| B | 任何外生信号到达就关本地读，不先判断前提 |
| C | 只有 `premise_holds is False` 才撤销并关本地读 |
| 无害变化 | 不改库存的标注事件。C 不得撤销。B 会断流 |

调度对照是 FIFO 和按任务类别长度事先固定的 SJF。等待达到 25 秒的任务老化到队首。长度不按实际生成事后修改。

## 4. 冻结的重复次数

协议文件在跑第一行真实数据之前写入 `results/experiments/v1_3/protocol/v22_protocol.json`。

- 有害变化：短/中/长 × 早/中/晚。Pilot 每格 4 个种子 × A/B/C。确认性每格 12 个新种子 × A/B/C，合计 108 对。
- 无害变化：同样 9 格。Pilot 每格 4 个种子 × B/C。确认性每格 20 个新种子 × B/C。
- 队列：高、中负载上 FIFO/SJF × A/B/C，每格 20 个独立 batch（一半 1 长 2 短，一半 4 任务混排）。低负载只跑 FIFO/SJF × A/C，每格 10 个 batch。统计单位是 batch。有工程意义的后续等待缩短事先定为 1 秒。
- 可恢复：短/中/长各 20 个种子 × A/B/C。失效后库存恢复。
- 工作流：库存预订（A/B/C）、先比较再预订（A/C）、计划中途前提失效（A/C），各 20 个种子。

确认性种子和 pilot 不重叠。不因为某一格好看就加跑。若 pilot 的槽位差标准差大于 1.5 秒，只允许把该格种子加到均值标准误低于 0.5 秒。传输失败、超时、限流单独记，不写成取消成功。

## 5. 测量

事件分开记录：`slot_acquired`、`slot_released`、`eligibility_revoked`、`local_read_stop_requested`、`local_read_stopped`、`provider_abort_not_issued`。差值用 `time.monotonic()`。wall clock 只写在用量里做标注。当前商业 API 不调用供应商取消接口，所以 `provider_abort_not_issued` 为真，服务端是否停生成仍是未知。

历史确认性 JSONL 不改。新结果只追加到 `results/experiments/v1_3/`。密钥只在仓库根的 `.env`，该文件已被 git 忽略。

## 7. 冻结结果

重算命令：`python -m uv run python scripts/analyze_v22.py`。汇总在 `results/experiments/v1_3/reports/v22_summary.json`。历史阶段 F 的 JSONL 没有改写。

模型是 `deepseek-chat`，流式。有害和无害确认性、队列、恢复、工作流里，`old_attempt_committed` 和重复副作用都是 0，传输错误是 0。

1. 普通断流解释了有害变化上的本地节省。三臂都触发的 74 对里，撤销到槽位释放的均值是 A−B 2.368 秒、A−C 2.373 秒、B−C 0.005 秒。撤销后文本是 A−B 316.8 词元、A−C 316.6 词元、B−C −0.2 词元。B 和 C 的断流速度没有可分开的差别。
2. 资格判断体现在无害变化。确认性 180 对里 B 撤销 146 次，C 撤销 0 次。C 没有把不改库存的标注当成前提失败。
3. 后续任务首次等待至少缩短 1 秒，这一点出现在 FIFO，没有出现在 SJF。中负载 FIFO 的 A−C 是 4.107 秒，区间 [2.993, 5.163]，整段在 1 秒以上。高负载和低负载 FIFO 的均值也超过 1 秒，但区间跨过 1 秒。SJF 的 A−C 均值是 0.146、0.435、0.844 秒，都不到 1 秒。低负载没有让 FIFO 的均值差消失。
4. 可恢复完成率用“有一次有效提交，且旧 attempt 没有提交”计算。短：A 0.85，C 0.90。中：A 1.00，C 0.95。长：A 1.00，C 0.90。点估计都没有低过 10 个百分点。长任务的配对差区间是 [−0.25, 0.00]，里面包含大于 10 个百分点的下降，所以长任务只是落在界限上，不是被区间钉死。
5. 工作流检查的是工具和提交，不只是回答文本。库存预订、先读再预订、计划中途失效都没有旧提交，也没有重复副作用。先读再预订的 40 次都在撤销前出现了工具调用，随后预订被拒绝，因为库存已经被外生变化打到 0。
6. 收益边界按长度和时机分开。确认性里，长任务早/中/晚的条件均值是 4.172、3.676、2.835 秒；中任务早/中/晚是 2.011、1.759、0.742 秒；短任务只有早时机有 0.453 秒，中、晚两格 12 对都没有双臂触发。短生成经常在变化到达前结束。把七个有数字的条件格池成 77 对是 2.335 秒，区间 [2.013, 2.650]。这个池化不是每一格都一样大。

Pilot 的撤销到释放标准差最大是长任务早时机 1.196 秒，没有触发“加种子直到标准误低于 0.5 秒”的规则。确认性因此保持每格 12 个种子。区间是配对重采样的 2.5% 到 97.5%，不是 Holm 显著性。

不在这轮做 2D 仿真、vLLM/SGLang 和第二套复杂调度算法。下一阶段改为旁观者队列测量，见 [项目开发文档3.0.md](./项目开发文档3.0.md)。
