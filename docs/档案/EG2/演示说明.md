# 演示说明

演示一条已经实际跑通的轨迹。没有跑通 M1 的七步之前，演示只说明协议和当前阻塞，不展示虚构的成功率。

终端里并排看同一任务的 Clean 和 Changed：checkpoint 前缀哈希、`evidence_read_set`、策略名、最终 patch、测试结果和成本。不另做聊天网页。

可以讲的设计：

- 三个 bundle 怎样声明 `dsh.bundle`，卸载时怎样撤销工具。
- 密钥留在宿主机，容器里没有它。
- checkpoint 为什么要等 turn 结束。
- Gateway 拒绝、非法候选和任务失败为什么是三本账。
- Trace Replay 和 Fresh API Rerun 为什么不能加在一起当样本量。

简历只写仓库里已经有的实现和审计结果。不写尚未测量的成功率或重做比例。
