## 1. 目录归类

| 路径 | 职责 |
| --- | --- |
| `src/epochgate/models.py` | 领域实体与调度可见裁剪视图 |
| `src/epochgate/registry.py` | 任务 / attempt；隔离 `plan_epoch` 与 `obs_revision` |
| `src/epochgate/observation.py` | 观测存储（source_version + sample_time） |
| `src/epochgate/scheduler.py` | 只读 `SchedulerSnapshot` → `Decision`；无副作用 |
| `src/epochgate/gateway.py` | **唯一**调用 `environment.commit` 的模块 |
| `src/epochgate/backend.py` | `InferenceBackend` 协议 + `FakeBackend` |
| `src/epochgate/environment.py` | `EnvironmentAdapter` 协议 + `FakeEnvironment` |
| `src/epochgate/events.py` | 追加式事件日志（内存；可选 SQLite 建表双写） |
| `src/epochgate/runtime.py` | 组装 snapshot、执行 Decision；禁止直接 commit |
| `src/epochgate/cli.py` | `epochgate demo` |
| `tests/` | happy path、stale 拒绝、架构守卫 |
| `examples/fake_dynamic_env.py` | 独立脚本演示 |
| `docs/` | 设计文档与本说明 |

仓库根就是项目根，**不再套一层**同名项目目录。`src/epochgate` 仅是 Python 包名（`import epochgate`）。

## 2. 依赖方向（必须遵守）

```text
cli / examples / tests
        ↓
     runtime
    ↙  ↓  ↘
scheduler  gateway  registry / observation / events
    ↓         ↓
  models   EnvironmentAdapter / InferenceBackend (Protocol)
```

约束：

1. `scheduler` 不得 import `gateway` / `environment` / `backend` 具体实现。
2. `scheduler.decide` 只接收裁剪后的 `SchedulerSnapshot`，不持有 registry / store / evaluator。
3. 只有 `gateway.py` 可以调用 `environment.commit`。
4. 时间统一 `time.monotonic()`。
5. 依赖仅限：pydantic、typer、pytest、pytest-asyncio。

## 3. Happy path

```text
任务登记 → begin_attempt
  → Decision.refresh → Environment.observe → ObservationStore.record
  → Decision.admit   → AdmissionLease
  → Decision.dispatch → FakeBackend → CandidateAction
  → ActionGateway.submit → check + commit
  → Decision.finish → TaskStatus.succeeded
```

## 4. 怎么跑

在仓库根目录：

```powershell
python -m uv sync --extra dev
python -m uv run pytest -q
python -m uv run epochgate demo
python -m uv run python examples/fake_dynamic_env.py
```

若本机没有把 `uv` 加进 PATH，一律用 `python -m uv`。

## 5. 替换后端 / 环境

实现 `EnvironmentAdapter` / `InferenceBackend` Protocol，构造 `Runtime(environment=..., backend=...)` 即可。**不必改** `scheduler.py`。
