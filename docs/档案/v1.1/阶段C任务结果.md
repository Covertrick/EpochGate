# 阶段 C：任务结果有效性

日期：2026-11-02。原始行在 `results/real/phase_c/`。与阶段一探索矩阵分开。代码快照为运行时的短哈希（工作树含阶段 B 口径）。

## 设定

| 类型 | 做法 | 成功条件 |
| --- | --- | --- |
| 静态 | 非流式 `reserve`，库存初值 3，无外生变化 | 恰好一次提交，库存 3→2 |
| 失效 | 流式 120 词，首增量后 0.5 秒库存改为 0；A 继续读，B `aclose` | 旧 attempt 不提交；期末库存 0 |
| 可恢复 | 同上降为 0，再过 1.0 秒 `apply_exogenous(+1)` | 旧 attempt 不提交；新计划恰好提交一次；副作用一次 |

### 失效（`invalidate.jsonl`）

| 种子 | 臂 | 成功 | 撤销后文本事件 | 工具事件 | 可观察词元 | 提交数 | 库存 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 601 | A | 是 | 184 | 8 | 183 | 0 | 0 |
| 601 | B | 是 | 0 | 0 | 0 | 0 | 0 |
| 602 | A | 是 | 143 | 8 | 140 | 0 | 0 |
| 602 | B | 是 | 0 | 0 | 0 | 0 | 0 |

B 臂撤销后事件与词元均为 0。A 臂仍收到文本与工具增量，但没有 `action_committed`。

### 可恢复（`recoverable.jsonl`）

| 种子 | 臂 | 成功 | 提交数 | 旧 attempt 提交 | 副作用一次 | 期末库存 |
| --- | --- | --- | --- | --- | --- | --- |
| 701 | A | 是 | 1 | 否 | 是 | 0 |
| 701 | B | 是 | 1 | 否 | 是 | 0 |
| 702 | A | 是 | 1 | 否 | 是 | 0 |
| 702 | B | 是 | 1 | 否 | 是 | 0 |

库存先被清零再恢复 1，新计划提交后库存为 0。取消臂与继续读臂都能完成一次有效提交；本探针不能用来宣称 B 提高了吞吐，只能说明可恢复路径在当前模型与提示下可行。

## 能同时报告的内容

- 取消效果：失效格上 B 的撤销后文本/工具事件为 0，A 仍大于 0；词元用冻结的 tiktoken 计数。
- 有效任务：静态与可恢复有恰好一次提交；失效无提交；可恢复旧 attempt 未提交。

供应商 `provider_completion_tokens` 若不能归因到被撤销 attempt，行为仍为 `UNKNOWN`。
