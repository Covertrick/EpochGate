# v2.1 机制与复现

## 机制

有害 G2 少占的是失效尾巴。早时机焦点服务 16 秒，事件在 3.2 秒，剩余 12.8 秒。G0 把这 12.8 秒占完再跑 successor。G2 在 3.2 秒放槽，successor 的服务量等于 \(\rho_h\times 12.8\)，和 G0 的 successor 一样长。所以下一手是 successor，旁观者仍然少等大约这段被省掉的尾巴，再被队列摊开。

无害 G2 不产生 restart，下一手是 bystander。G1 每次都产生一次 restart，服务量等于 \(\rho_b\times 12.8\)。\(\rho_b<1\) 时 restart 比剩余有效服务短，误撤减少占用，旁观者 P95 更低。

G2-delayed-release 把槽占到原服务结束，队列时间线与 G0 重合。旁观者收益依赖于事件当时就放槽。

低负载中位数等待是 0，ΔW95 也是 0。没有排队时，释放没有旁观者可改变。
