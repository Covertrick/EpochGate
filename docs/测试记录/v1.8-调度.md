# v1.8 调度与负载

日期：2026-11-02。统计单位是 batch。原始行 `results/experiments/v1_3/queue/batches.jsonl`，980 行。高负载和中负载是 FIFO/SJF × A/B/C，每格 20 个 batch。低负载是 FIFO/SJF × A/C，每格 10 个 batch。每个格的前一半是 1 长 2 短，后一半是 4 任务长短混排。长度按任务类别事先固定。老化时间 25 秒。传输错误 0。旧 attempt 提交 0。

下表是后续任务首次等待的 A 减另一臂，按 batch 配对。预先写下的工程界限是至少 1 秒。

| 负载 × 调度 | A−C 均值（秒） | 区间 | 均值达到 1 秒 |
| --- | ---: | --- | --- |
| 高 FIFO | 2.010 | [0.627, 3.309] | 是，区间跨过 1 秒 |
| 中 FIFO | 4.107 | [2.993, 5.163] | 是，区间整段在 1 秒以上 |
| 低 FIFO | 3.226 | [0.763, 6.122] | 是，区间跨过 1 秒 |
| 高 SJF | 0.146 | [−0.636, 0.883] | 否 |
| 中 SJF | 0.435 | [−0.555, 1.341] | 否 |
| 低 SJF | 0.844 | [−0.543, 2.084] | 否 |

A−C 的 1 秒缩短只出现在 FIFO。SJF 没有达到这个界限。低负载没有让 FIFO 的均值差消失，所以不能写成“只有排队很挤才有收益”。高负载上 A−B 的均值是 2.850 秒，大于 A−C 的 2.010 秒：普通断流有时比前提门闩更早让出队头，这和“B 与 C 的断流速度本身没有额外差”是同一件事，资格判断才是 C 的增量。
