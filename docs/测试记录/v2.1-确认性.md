## 结论句

这组表对应的是混合结果，不是单一的 A 或 B。

有害主格上，提前释放（G2 相对 G0）在三种调度、\(\rho_h\in\{0.5,1,2\}\) 和中、高负载上都缩短了旁观者 P95 等待，并跨过预先冻结的 10% 门槛。收益不限于 FCFS，也不随 \(\rho_h\) 反转。完成时间同向变短，但相对幅度没有跨过 10%。

无害主格上，选择性不是单调收益。\(\rho_b=2\) 时 G2 优于误撤；\(\rho_b=1\) 时等待差为 0；\(\rho_b=0.5\) 时 G2 的旁观者 P95 更差。这是结果 D 的格子，留在主表里。

因此可以写：在这个 Runtime 槽回放里，前提失败后的立即释放会减少旁观者等待；前提仍成立时，是否误撤对旁观者有利，取决于 restart 相对剩余有效服务的长短。不能写：G2 在所有负载和调度器上更优，也不能写调度器改变了效应方向。
