# v5.0 方向 A 实验协议（冻结）

冻结日：2026-11-04。机器可读副本：`results/experiments/v5_0/protocol/v50_protocol.json`。合同：`docs/开发文档/项目开发文档5.0.md`。

## 1. 研究目标

状态触发撤权在客户端与后端资源释放语义可能不一致时，如何影响独立工作流延迟。分别建立：

1. DeepSeek API 上的**客户端可观察**收益 / local–e2e 分离（D1–D3）。
2. 可观测 serving（vLLM）上的**机制可识别**收益 / 反转边界。

证据前不写「我们解决了」。

## 2. 三资源与处理组

| 资源 | 含义 |
| --- | --- |
| Runtime slot | 本地 `max_inflight` 槽 |
| API stream | HTTP 流 |
| Backend generation | 服务端推理占用；黑盒不可观测 |

| 臂 | Runtime | Stream | Backend | DS 允许 |
| --- | --- | --- | --- | --- |
| G0 | 撤权后持槽至自然结束，再放槽并派 successor | 继续读，丢弃输出 | unknown | 是 |
| G2-local | 停读后立即放槽 | aclose | **强制 unknown** | 是 |
| G2-residual | 同 G2-local 立即放槽 | 可停读 | 注入/观测残余 D | **否** |
| G2-hold-slot | 资格撤销但槽延迟释放 | 可停读 | 不声称 GPU | 回放/脚本 |

G0：若撤权前已完成，记 `pre_revoke_completed`，分层或剔除，不混主效应。

## 3. DS：D1 / D2 / D3

- **D1** 本地队列外部性：G0 vs G2-local；S=2；B=8 独立 bystander；主张上限=客户端可观察。
- **D2** \(W_{\mathrm{slot}}\) 与 \(T_{\mathrm{e2e}}\) 分离；TTFT 另列，不与 slot 混用。
- **D3** 取消链状态；无证据 → `backend_stop_status=unknown`；禁止 aclose→残余=0。

负载：固定 prompt / `max_tokens=512` / `temperature=0` / `deepseek-chat`。同 seed 到达序列共享；臂交错、随机先后。主 P95 仅双臂均成功的配对 trace。观察窗 H=300s。

种子：开发 6000–6014；确认 7000–7049（每格 50）。确认主格：有害早触发 × {中、高负载}。

## 4. 统计

单位=trace。每 trace 对 B=8 算 P95（线性插值）。配对差 bootstrap 10000 次，种子 20261104。禁止 bystander 当独立样本。报告每 trace bystander 数、未完成、失败、删失。

## 5. 门槛与 \(M_0\)

- 工程：相对 ≥10%，且 bootstrap 2.5% 分位与 0 异侧。
- 零效应带 \(\tau\)：开发后冻结；暂定 `max(0.05, 0.02×baseline_p95)` 秒。
- \(M_0\)：\(\widehat{\Delta T}=\alpha\Delta U_{\mathrm{client}}+\beta\)，仅中负载开发集拟合；高负载留出。显著残差：留出均值残差 95% CI 不含 0 且 \|均值\|≥\(\delta\)（暂定 0.20s）。

## 6. Go / No-go

| 判定 | 条件 |
| --- | --- |
| DS Go | D1 或 D2 过工程门槛；D3 无残余=0 误标 |
| vLLM Go | 稳定分离或 \(M_0\) 显著残差；至少 L2-a/b；留出方向对 |
| 总 Go | 须 vLLM Go |
| 仅 DS Go | 测量贡献成立，机制创新 No-go |

## 7. vLLM 观测级

L2-a 请求终止态；L2-b 出调度队列；L2-c 资源指标。禁止 a/b 升级为 c。兼容性测试通过前不进机制确认性。

## 8. 不碰

v2.1 确认性 JSONL 只读。不把 aclose 写成 GPU/KV 回收。确认格冻结后不因看图增删。
