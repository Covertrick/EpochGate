## L0（本机脚本残余）

- 命令：`python -m uv run python scripts/run_v50_l0.py`
- 产物：`results/experiments/v5_0/l0/traces.jsonl`，`l0_summary.json`
- 观察：在 `scripted_max_tokens=12`、`token_interval=0.01`、`S=2` 下，多数种子的 bystander \(W_{\mathrm{slot}}\) P95 为 0（本地槽未形成排队）；\(T_{\mathrm{e2e}}\) 偶发随 `G2-residual` 的 D 上升。`M0` 草稿 `alpha≈0.004`，信号弱。
