# 快速开始

控制面命令是 `egctl`。研究仓库里的 `epochgate` 仍然是原来的入口，两者不共用同一个命令名。

只安装控制面时，在仓库根执行：

```powershell
uv tool install ./packages/runtime
egctl doctor
egctl demo --scenario stale-write --offline
```

在仓库里开发时可以不先安装：

```powershell
uv run egctl demo --scenario stale-write --offline
uv run egctl demo --scenario crash-recovery --offline
```

离线 Demo 不调用模型。每次使用新的 Run ID，数据在 `.epochgate/`。重复执行不用删除 SQLite。

报告在 `.epochgate/runs/<run-id>/report.json` 和同目录的 `report.html`。查看时间线：

```powershell
uv run egctl runs list
uv run egctl runs inspect <run-id>
uv run egctl effects verify <run-id>
```

`stale-write` 的第一个 token 不能发布，第二个 token 发布一次。同一键再发布不会改文件。`crash-recovery` 让 Worker 在 receipt 写入前退出，重新打开账本后补上同一次效果。
