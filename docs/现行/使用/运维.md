# 运行和恢复

配置样例是 `deploy/epochgate.example.yaml`。`egctl init` 在文件不存在时写出 `epochgate.yaml`，并初始化 SQLite。已有配置不会被覆盖。账本 schema 版本当前是 1，打开旧文件时会补上缺失的列。

停止服务用 Ctrl+C。它把 `server.json` 标成 `stopped` 并关闭数据库。再次执行 `egctl serve` 会打开同一本账本。pid 仍显示为运行中时，新进程会退出，避免两个写者。

进程被直接杀掉时，已提交的事务还在。未提交的写入由 SQLite 回滚。之后可以：

```powershell
uv run egctl runs list --data-dir .epochgate
uv run egctl runs inspect <run-id>
uv run egctl effects verify <run-id>
```

`effects verify` 只在该 Run 有完成且带 receipt 的效果时返回 0。没有 receipt 时返回 1。

`egctl doctor` 区分三档。Python、账本和数据目录写入都失败不了，状态是 `blocked`。Node、DSH、插件或 Docker 缺一项，状态是 `degraded`，离线 Demo 仍可运行。Docker 检查的是 WSL 发行版 `eg-alpine` 里的 daemon，以及 `OSType: linux`。它不启动容器，因此不把一次真实挂载探测写成已经完成。默认沙箱不配置宿主机 bind mount。
