# 在线 Agent 的 B0 / B1 / B2

实验设计仍是下面这张对照。2026-11-10 的原始 batch 秒和 token 已经有了。响应里没有价格，n=3，不写 P95/P99 置信区间。

## 对照

三组使用同一个模型、同一条任务、同一种容器隔离。差别只在控制面：

| 组 | 控制面 |
| --- | --- |
| B0 | 工具在隔离环境里执行，不经过 EpochGate 资格和账本 |
| B1 | 只做资格检查，不写最终 receipt |
| B2 | 资格、fencing token、账本和发布 receipt 都打开 |

并发档是 1、2、4、8。每一档至少重复 3 次。一次重复是该并发下整批任务的墙钟时间。

## 要报告的量

- 吞吐：完成的 Run 数除以墙钟秒。
- 延迟：每批墙钟的 P50、P95、P99。样本少于 20 时不把极差写成置信区间。
- 费用：API 返回的 token 用量乘以当时价格。响应里没有用量就不填费用。
- 正确性：同一套评分下每组的完成数和失败归因。
- 隔离：工具容器 `--network none`，不挂载 docker socket，密钥不进入容器。

## 当前状态

2026-11-10 跑过。模型请求名和响应里的 `model` 都是 `deepseek-flash`。任务是写出让 `bug.value()` 返回 1 的 `bug.py`。三臂容器都是 `python:3.10-slim`，`--network none`，非 privileged，挂载数 0，看不到 docker socket。B2 把 `/workspace` 锁给 uid 1001。时钟包含 API 和工具落地，不包含容器启动。

并发 1 的 9 次调用都是 `total_tokens=39`，合计 351。其中一次是 prompt 32、completion 7。响应没有价格，费用空着。三次评分都通过。B0 没有账本，B1 停在 `INTENT_RECORDED` 且没有 receipt，B2 发布成功并有 receipt。三次 batch 秒：B0 是 1.599、1.934、1.600；B1 是 2.180、1.740、1.696；B2 是 3.421、2.919、2.640。文件是 `results/runtime/online_b0b1b2.json`。

同文件里的并发 2 有一次因两个线程共用 SQLite 连接而丢样本，`concurrency_2_first_attempt.valid_measurement` 是 false。干净重跑在 `results/runtime/online_scale.json`。并发 2/4/8 每臂 3 次，每次 39 token，合计分别是 702、1404、2808。每个格子 3/3 评分通过。B2 有 receipt，B0 和 B1 没有。原始 batch 秒以 README 和 JSON 为准。n=3，不写 P95/P99 置信区间，也不把 B2 更长写成通用开销。

`results/runtime/benchmarks/w0_scale.json` 仍是另一项测量：本机 Python 进程睡眠 0.05 秒。它不能填进这张在线表。

## README 上两张图的原始中位

在线 batch 中位秒，n=3。B0 没有账本，B1 停在意图，B2 才有 receipt。三臂业务结果不同。并发 1 来自 `results/runtime/online_b0b1b2.json`。并发 2/4/8 来自 `results/runtime/online_scale.json`。同文件里第一次并发 2 的 `valid_measurement` 是 false，不进入下表。

| 并发 | B0 | B1 | B2 |
| --- | --- | --- | --- |
| 1 | 1.600 | 1.740 | 2.919 |
| 2 | 3.829 | 4.701 | 5.278 |
| 4 | 3.961 | 5.180 | 6.676 |
| 8 | 5.538 | 7.598 | 9.940 |

公平提交开销，各 20 次，并发 1。三臂同一次 `deepseek-flash` 调用，同一次载荷 `OK`，都完成。汇总在 [主数字](../论文/数据/01-主实验/主数字.md)。

| 臂 | 总时间中位 | 提交段中位 |
| --- | --- | --- |
| B0 只检查 sink 版本 | 0.878 秒 | 0.096 秒 |
| B1 `commit_authorized` | 1.034 秒 | 0.283 秒 |
| B2 再打开账本读 receipt | 1.067 秒 | 0.283 秒 |

这一次短调用上，B2 总时间中位比 B0 高 (1.067 − 0.878) / 0.878 ≈ 21.5%。这是该工作负载上的观测。
