# 代码地图

写架构节时按这条链，不要把研究包 `epochgate` 写成当前控制面。

| 部分 | 路径 | 做什么 |
| --- | --- | --- |
| 包 | `packages/runtime` | 可安装包 `epochgate-runtime` 0.1.0。导入名 `epochgate_runtime` |
| 账本 | `packages/runtime/src/epochgate_runtime/ledger.py` | `RunLedger`。fencing token、`state_version`、效果阶段、receipt。`supersede(run, sink)` 同时推进 token、版本和 sink；不传 sink 只推进 Run。`commit_authorized` 在 `BEGIN IMMEDIATE` 里核对三者。效果已经是 `started` 或 `unknown` 时返回 `unknown`，不写 sink |
| 接收器 | `packages/runtime/src/epochgate_runtime/sink.py` | `EffectSink`。版本从 1 起。版本不对就拒绝。重放不增加接受次数 |
| HTTP | `packages/runtime/src/epochgate_runtime/service.py` | `/runs`、`/admit`、`/effects/reserve`、`/effects/commit`、`/effects/publish-file`、`/runs/{id}/supersede`、`/runs/{id}/revoke` |
| 文件发布 | `packages/runtime/src/epochgate_runtime/files.py` | `publish_file` 调用 `claim_publish`。核对的是 fencing token，不读 EffectSink 版本 |
| 容器发布 | `packages/runtime/src/epochgate_runtime/sandbox.py` | `publish_container`。发布用户 uid 1001，工具用户 uid 1000 |
| 进程取消 | `packages/runtime/src/epochgate_runtime/processes.py` | 记录停止和退出。槽位在进程退出后释放 |
| DSH 插件 | `packages/eg-workspace/lib/index.js` | `eg_read` 只准入。`eg_write` 先 reserve 再发布。`EG_PUBLISH_GATE` 只在实验里把第一次发布停在 reserve 和 publish 之间 |
| 插件策略 | `packages/eg-policy`、`path-guard.js` | 可以提前拒绝。不能代替账本授权 |
| 主实验脚本 | `scripts/runtime_paper_campaign.py` | 包 B、D、A 的三例模型提交、包 C 公平开销 |
| DSH 撤销脚本 | `scripts/runtime_dsh_revocation.py` | 两条多步会话 |

研究包 `epochgate` 5.0.0 和 `import epochgate` 不在这条链上。默认的根目录 pytest 收集的是研究测试。产品测试是 `uv run pytest packages/runtime/tests`。

副本在同目录：`运行时.md`、`插件.md`、`安全边界.md`、`现状清单.md`，以及 `协议/`、`基准/`、`复现/`、`使用/`。原文仍在 `docs/现行/`。
