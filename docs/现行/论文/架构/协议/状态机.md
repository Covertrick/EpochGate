# 状态

Run、工具副作用和执行租约分开存放。

Run 使用 `created`、`running`、`cancel_requested`、`stopping`、`stopped`、`unknown`、`reconciled` 这些阶段。`committed` 不能再回到 `running`。

工具副作用使用 `INTENT_RECORDED`、`DISPATCHED`、`STARTED`、`EXITED`、`RESULT_PERSISTED`、`NOT_APPLIED`、`OUTCOME_UNKNOWN`、`CANCELLED_CONFIRMED`。命令路径从 `INTENT_RECORDED` 进入 `STARTED`，看到退出码后进入 `EXITED`，token 仍匹配才记成 `RESULT_PERSISTED`。没有退出码、token 已过期，或外部系统不能条件提交时，停在 `OUTCOME_UNKNOWN`，同一键再来不会再记一次。`RESULT_PERSISTED`、`OUTCOME_UNKNOWN`、`CANCELLED_CONFIRMED` 不会被后一次退出码改写。Run 已经撤销时，一项工具仍可能已经写进接收器；恢复时按接收器的行决定是确认还是未知，而不是看 Run 阶段。

租约使用 `held` 和 `released`。释放租约要有进程退出记录。租约释放不表示 GPU 已回收。
