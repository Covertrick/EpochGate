# 相关工作核对

核对日期：2026-11-10。三篇 arXiv 用的是当天下载的 PDF。页码是这些 PDF 的页码。DelAct 的正文没有公开 PDF 直链，下面只使用书目和 Semantic Scholar 保存的摘要。

EpochGate 不把这些机制说成自己首次提出。下面只写本文测量到的边界，和对方论文自己报告的范围。

## 提交时授权

Santos-Grueiro，*Temporary Authority, Permanent Effects: Commit-Time Authorization for LLM Agents*，arXiv:2607.10487，18 页。

第 1 页把问题放在批准观察和稍后提交之间：批准被撤回或覆盖的不是这次效果时，服务仍可能写入并报告成功。第 3 页的 COMMITGATE 在效果变持久的那一次操作里检查当前授权。第 9 页的受控研究给模型一个失效标记，不允许它重新验证。Qwen 提交了 207 次被标记的执行；262/270 次端点成功，授权完成是 55/270。第 17 页表 18 把这 270 次拆成浏览器、工具状态和多 Agent。

本文的对应测量窄得多。两条 DSH 会话只改一个库存文件。没有通知时，`order 3` 在库存已经是 0 之后被发布。对齐 `supersede` 之后，token 1 被拒，token 2 发布 `order 0`。这不能拿来复现对方的 54 个任务或 262/270。对方还要求证据槽、授予和候选选择；本文的文件发布只核对 fencing token。

## Cordon

Chen 等，*Cordon: Semantic Transactions for Tool-Using LLM Agents*，arXiv:2606.17573v1，EuroSys ’27，14 页。

第 1–2 页把一次任务定义成语义事务：血缘、影子状态、效果 outbox，验证之后才发布外部效果。第 2 页报告 45 个有风险的多工具流程里，普通执行 45/45 提交了违规效果，既有防御适配器在提交前拦住 14/45，Cordon 拦住 45/45。去掉审批等待后，平均任务时间下降 24.6–27.9%，token 下降 23.6–28.4%，回滚中位 4.17 ms，15/15 次恢复检查通过。第 8 页把崩溃后的状态分开：没有持久回执的已准备事务可以自动中止；只有部分回执的执行中事务要人工复查；已经派发的外部效果，没有幂等证据就不重发。

本文没有影子工作区，也没有任务级 outbox。`eg_write` 在单次发布时检查 token。已经发布的 `order 3` 不会被事后的库存变化撤销。四个崩溃点的 sink 接受次数是 0、0、1、1，用来区分未生效和已生效，不对应 Cordon 的 4.17 ms 回滚。

## From Evidence to Effect

Li 等，*From Evidence to Effect: Authority Semantics and Runtime Infrastructure for Stateful Agents*，arXiv:2609.08472v4，36 页。

第 1 页摘要：原始证据和带类型的证据都解决 32/32 个授权案例；固定意图拦截 6 个不安全提议并执行 12 个合格意图；付费集成接受 176/210 个阶段，其中发布阶段 19/30，8 个主要 SWE 仓库的恢复是 8/8。第 3 页的 Fresh 要求贡献者的当前尝试、匹配的完成回执，以及记录的那一代权限。本地提交在一个事务里检查、消耗批准并记录效果。外部接收方按效果键最多插入一次；响应丢失后，已生效返回回执，确认不存在才允许重试，不能确认就保持 pending。

本文的 `supersede(run, sink)` 把 token、Run 版本和 sink 版本一起加一。DSH 的 `publish-file` 不读 sink 版本，只拒绝过期 token。没有批准消耗，没有跨仓库恢复，也不报告 176/210 这类阶段接受率。

## DelAct

Zhang、Liao、Guo、Tang，*DelAct: A Replayable Boundary Runtime for Auditable and Governed LLM Agent Workflows*。IWQoS 2026 短文，DOI `10.1109/IWQoS70441.2026.11661202`，Crossref 记录页码 1–6，2026-06-01，Unpaywall 标为 hybrid、CC-BY，但 `url_for_pdf` 为空。作者主页上的 PDF 指向飞书，打不开正文。

Semantic Scholar 保存的摘要说：DelAct 把思考和执行拆开，控制面不产生副作用，数据面用 commitment hash 把意图绑到稳定标识，用于幂等执行、不确定结果的核查和补偿回滚，观测面保存只追加的事件日志。评估是 Ticket/Invoice 流程上的超时和部分失败。摘要给出的结果是：完整治理去掉超时造成的重复写入和失败后的残留写入，回滚平均修复时间 66.5 ms。这些数字没有在正文页上复核。

在这个摘要范围内，本文与它重叠的是幂等键、`UNKNOWN` 不再自动执行，以及事件日志。本文没有补偿回滚，也没有 Ticket/Invoice 故障注入。四个崩溃点只报告 EffectSink 接受了 0 次还是 1 次。
