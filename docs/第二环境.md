# 第二环境

主环境实验不依赖这里。本轮没有把 Gaia2 或 RealtimeGym 的源码拷进仓库，也没有报告官方榜单或跨环境名次。`second_environment_status()` 的 `ranking` 是空。

## Gaia2

Gaia2 的场景是多应用异步用户模拟。官方验证器绑定 ARE 的应用状态，动作不是本仓库的 `observe` / `commit`，也没有 `source_version` 条件提交。

要对齐粒度，就得带上整套 ARE 运行时。许可证不允许把场景再分发进本仓库。因此不实现 `EpochGate-Gaia2-Subset`，也不写官方榜单数字。

## RealtimeGym

粒度对不上 Gaia2 之后，按计划改看 RealtimeGym 的时间预算模式。它用时间或 token 预算推进环境，任务动作仍然不是库存式条件提交。官方环境不在本仓库依赖里。本轮不安装、不改编它的判分。

## 现在停在哪里

适配器接口是 `src/epochgate/public_env.py` 的 `second_environment_status()`。两个环境的 `available` 都是 false，并写明上面的原因。能跑通之前，不比较同一策略在库存和第二环境上的名次，也不编造排序不一致的解释。
