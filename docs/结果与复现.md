# 结果与复现

主数字来自包版本 3.0.0 的逻辑时钟回放。当前包是 4.0.0，没有改这些 JSONL 里的 `code_version`。

协议哈希 `37f9846b2504b61c4e535940f9cc4df741fe9b462d6f99458b55a40ee2138213`。确认性种子 5000–5049，每格 50 条。Bootstrap 以 trace 为单位，10000 次，种子 20261103。

门槛在确认性之前冻结，两条同时成立才算跨过：

1. 点估计相对基线至少 10%。
2. 绝对差的 bootstrap 2.5% 分位大于 0。

这不是“区间证明至少改善 10%”。完成率下降超过 2 个百分点算伤害。确认性里这个差是 0。

## 真实 API

60 条长任务，种子 9100–9109，传输错误 0。旧提交 0。无害 G1 误撤 10/10，无害 G2 为 0/10。有害 G2 的撤销、本地停读、槽释放都出现。9/10 的顺序是撤销、停读、放槽；种子 9104 的放槽比本地停读早 0.015 秒。两个任务同时在飞，不进主表。
