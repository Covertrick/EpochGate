# v5.0 确认性 — DeepSeek V4.1-Flash

日期：2026-11-04。模型 API 名 `deepseek-flash`（产品 DeepSeek-V4.1-Flash）。`thinking` 关闭。`max_tokens=512`，`temperature=0`，无工具循环。

产物：`results/experiments/v5_0/ds/dev/traces.jsonl`（种子 6000–6014，中负载）、`results/experiments/v5_0/ds/confirm/traces.jsonl`（种子 7000–7049，中负载与高负载各 50 对）。

## 合同是否被遵守

- 臂只有 G0 与 G2-local。
- G0：撤权后继续读到自然结束（确认性格焦点 `output_tokens=512`，`closed_early=false`）。
- G2-local：撤权后 `aclose`（确认性格 50/50 `closed_early=true`，输出增量少于 512）。
- `backend_stop_status=unknown`，`residual_lower_s` 为空。没有把断流记成残余 0。
- 到达：中负载旁观者偏移落在 12 秒窗；高负载落在 6.4 秒窗。同种子两臂共享偏移，臂序随机。

工程门槛是相对 ≥10% 且 2.5% 分位与 0 异侧。

- 本地槽等待：中、高负载都过门槛。
- 端到端：中负载过门槛；高负载绝对差的区间在 0 以上，但相对值 8.6% **未过** 10%。
- D2 分离（槽等待下降而端到端不降）：**没有**稳定出现。两边多数同号变短。

## 主张上限

这是真实 `deepseek-flash` 上的**客户端可观察队列外部性**。两档端到端差都为正且区间不含 0，但高负载相对 8.6%，没有过预登记的完整工程门槛。槽等待与端到端同向变短，D2 期待的分叉没有出现；这不是 5.0 测量失败。

G0 与 G2-local 同时改变了是否继续读流和何时释放 Runtime slot。0.86–0.92 秒的端到端差兼容本地队列、服务端取消、两者并存，以及 API 时长与 token 波动。当前记录分不开这些解释。\(T_{\mathrm{e2e}}\) 从到达计时，不等于服务端排队时间。

不能证明 DeepSeek 服务端已经停止生成，也不能证明后端残余导致反转。
