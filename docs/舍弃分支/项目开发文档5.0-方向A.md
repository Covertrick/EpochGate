# EpochGate 5.0 方向 A 合同

包版本目标 **5.0.0**。4.0 确认性与论文保留为理想化参照，不重跑。协议细节以 [v5.0-协议.md](./v5.0-协议.md) 与 `results/experiments/v5_0/protocol/v50_protocol.json` 为准。

## 这篇要交什么

双层证据：

1. **DeepSeek API（D1–D3）**：真实黑盒服务下，客户端撤权并释放 Runtime 槽，对独立 bystander 的可观察等待与端到端影响；以及 local/e2e 是否分离。
2. **vLLM**：可观测后端上，残余/出队与旁观者延迟的机制边界。

总 Go（「不能被预设服务量 + 已知取消直接解释」的机制版）要求 vLLM Go。仅 DS Go 时论文降为测量贡献。DS 确认性已经跑完，下一阶段合同是 [项目开发文档5.1-方向A.md](./项目开发文档5.1-方向A.md)，不再扩大实验矩阵或另开方向。

## 运行顺序

1. `pytest` 与 `scripts/run_v50_l0.py`（本机 L0）
2. 有 API key 时 `scripts/run_v50_ds.py --phase dev`，标定后 `--phase confirm`
3. GPU 机：兼容性 `scripts/run_v50_vllm_compat.py` → pilot → confirm
4. `scripts/analyze_v50.py` → 写确认性文档与 go/no-go
