# 论文 5.0：在途撤销的三态决策

日期：2026-11-05。基线是论文 4.0，不是已经放弃的 DeepSeek 方向。

**现在不能把这篇投到 arXiv。** 决策函数和一轮离散回放已经落地，但回放没有把三态决策测成旁观者效应，运行时闭环也没有达到方案里的 Gate 3。近邻已经覆盖「撤权后重做」和「提交时拒绝再跑」。

## 已经实现的部分

| 对象 | 状态 |
| --- | --- |
| `src/epochgate/decision_policy.py` | 已实现。谓词无效则 `abort-and-replan`；候选已形成则交给 Gateway；否则用 \(\Delta=\hat C-\hat S\) 和误差带 \(m\) 在继续、重做、`continue/defer` 之间选择 |

| 安全计数 | 汇总里 `old_attempt_committed` 与 `duplicate_side_effects` 都是 0，完成率都是 1 |

带外动作和合成 Oracle 的差异数等于 defer 次数：121,500 条 UncertaintyAwarePolicy 里有 24,300 条是 `continue/defer`，其余 97,200 条的动作标签与 Oracle 相同。这是同一套合成谓词上的标签对照。方案把带内不计为错误，所以写成「一致率 100%」只在这个计分规则下成立。

## 数据上还不成立的部分

1. **策略名和回放臂不一致。** `AlwaysContinue` 全部回放成 G2。4.0 的 G2 在有害前提上会放槽，不是「一直继续读」。有害、中时机、高负载、4 槽、\(\rho=1\)、误差 25%、FCFS、种子 5000 这一格上，五种策略的旁观者 W95 都是 3.197 秒，放槽时刻都是 8.0 秒。这张表没有把决策差传到旁观者等待。
2. **`continue/defer` 没有自己的队列行为。** 决策是 defer 时，脚本仍用 G2 回放。误差带内「不强行切换」只存在于决策函数，不存在于旁观者指标。
3. **没有按方案做 bootstrap。** 汇总只有 cell 均值，没有 10,000 次配对区间，也没有「至少两个负载优于一个固定策略」的检验。
4. **运行时闭环没有做。** 方案要求 3 批 × 20 个任务 × 4 类场景，至少 240 个 attempt，并记录决策、估计误差、Gateway 检查和取消回执。仓库里被当成闭环的 `results/experiments/v5_1/vllm/groups.json` 是舍弃支线的四组一次探测：abort 计数没有增加，KV 没有采到。Gate 3 不通过。
5. **谓词真值由工作负载标签给出。** 这不能写成语义检测器的准确率。

Gate 1 通过。Gate 2、Gate 3、Gate 4 不通过。不准备 arXiv。

## 和近邻的关系

- Retire，arXiv:2610.01160，已经在 vLLM 上把在途修订做成版本化撤权、隔离和后继接手，并报告 revision-to-successor TTFT。不能再写「撤权后再规划」或「取消不等于立刻回收」为本文创新。
- Authority at Commit Time，arXiv:2609.31490，已经规定提交时依赖变化则 reject-stale 并重跑。Gateway 的「过期提交为 0」与这条重叠。
- Cost-Aware Speculative Execution，arXiv:2606.07846，已经用期望价值决定继续还是取消推测执行，并要求副作用不能在提交前放出。
- BDI 文献里的 Aborting Tasks 已经区分失败和主动中止，并讨论中止后的清理。

还没有被这些工作占住的窄问题是：估计误差带内明确拒绝宣称最优，并把这个三态决定和旁观者等待放在同一条可审计事件链上。当前矩阵没有测出后半句。在补上独立的 defer 队列行为、正确的继续持槽对照，以及带区间的旁观者差之前，这句话也不能当论文贡献。

## 还要补什么才能再判断
