# 论文图表与数据规划

这一阶段不画图，不手填期望数字。生成时只读下列路径。

1. 状态与效果证据的结构。来源 `docs/研究/执行语义与保证边界.md`。脚本只排版，不读模型输出。
2. 安全、终态、后继三列。来源旧 E4 格子。脚本 `scripts/paper_ledger.py` 的 `e4_old_360`。新 120 另表。
3. 一次准入与版本检查。来源同一 360 格的 direct、commit_only、full。
4. 非语义版本变化与内容失效。来源 `results/runtime/correctness/v4b-coding/summary.json` 与 `results/runtime/correctness/v4b-historical/summary.json`。
5. Claim 到字节与收据恢复。来源 `results/runtime/correctness/final-regression/summary.json` 和 `packages/runtime/tests/test_publish_process_kill.py`。
6. Coding 三张分开的表。v3 rescore、v4 confirm、v4c summary。脚本不得把三列加总。
7. Outbox、Full、LangGraph 的能力边界。来源 `results/runtime/correctness/outbox-baseline/summary.json` 与 `results/runtime/correctness/langgraph-boundary/summary.json`。
8. E7/E8 成本。只引用当时的成本记录。不用 final-regression 的耗时，不用 Outbox 的本地 SQLite。

图注必须写分母、协议版本和 `FIXED_FAILURE_FEEDBACK` 或 `unmeasured`。
