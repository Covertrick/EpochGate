## 1. 这篇论文是什么

测量共享槽上，状态触发的在途撤销如何改变与这次状态无关的旁观者等待。G0、G1、G2 是处理组。不提出新的取消算法，不给出通用最优阈值，不声称供应商已停止生成。

面试时用三句，细节回论文对应节：

| 发现 | 一句话 | 论文位置 |
| --- | --- | --- |
| 有害早放槽 | 4 槽、早时机，G2 相对 G0 的旁观者 P95 等待，12/12 主格跨过门槛 | 第 5.1 节 |
| 下一手可以是后继 | 有害 G2 的下一槽 600/600 是 successor，旁观者仍然少等 | 第 6 节 |
| 无害随 \(\rho_b\) 反转 | 0.5 变差，1 在早时机精确为 0，2 变好 | 第 5.2 节 |

完成率两侧都是 1.0，没有完成率结论。低负载和 8 槽上等待差消失，因为没有排队。

## 4. 主文写什么，附录写什么

主文只放四件事：

1. 有害 12 格的 P95 差、区间、相对值和门槛。
2. 无害 9 格，包括负的和精确为 0 的格子。
3. 下一槽持有者，以及种子 5005 的时间线作为例子。
4. Runtime-PLAS 与 FCFS 在无害路径和有害 G2 上顺序相同。

附录放：P90 与 P99 同号、完成时间同号但相对不足 10%、完成率全是 1、延迟释放与 G0 的 20 条边界、留一、敏感性 198 格、60 条 API 事件链。

不写进主句的句子：

- 8 槽上相对值接近 1。基线本身接近 0，这是分母造成的，不是 100% 改善。
- 三种调度器各自独立复现了放槽决策。有害格子的幅度差来自 G0 基线。
- 完成率提高。两侧都是 1。
- 回收了 GPU 或 KV。回放没有供应商，API 检查也没有取消回执。
- 发明了 queueing externality。Vesta 已经用这个词给放置开销定价。

## 5. 审计结论

这些检查不重写确认性。重算 2400 行的 \(W_{95}\) 与 JSONL 不一致的条数是 0。审计解释器是 `uv` 下的 Python 3.12.2。

| 检查 | 结果 | 写进论文时怎么用 |
| --- | --- | --- |
| 留一 | 没有一格的均值跨过 0。有害相对改善的留一最小值 ≥ 0.107，最差是中负载 SRPT、\(\rho_h=2\) | 说明不是单条种子撑起均值。仍要报告 9/50、7/50 这类负种子 |
| P90 / P95 / P99 | 21 个配对格符号一致 | 主文继续只报预先登记的 P95 |
| 完成时间 | 有害同号变短，相对约 0.058–0.100 | 与等待分开，不说完成时间也跨过 10% |
| 完成率 | 1.0 | 不写完成率结论 |
| 延迟释放 | 20 条上与 G0 的均值都是 14.233 秒 | 机制对照，不与 50 条主格同等强度 |
| PLAS 对 FCFS | 无害 7399 次可比较派发，顺序差 0。有害 G2 与 G1 也是 0。差只出现在有害 G0 | 幅度差来自基线占槽，不是 G2 被两种调度器不同执行 |
| 8 槽 | 绝对差约 0.006–0.024 秒，区间含 0。无害 \(\rho_b=0.5\) 变成 0 | 与低负载同一件事：没有队列就没有旁观者收益 |
| 2 槽 | FCFS 绝对差大约 7.9 / 12.5 / 6.2 秒，相对大约 0.069 / 0.101 / 0.048 | 绝对差大，相对常过不了 10% |
| 噪声与抖动 25% | 有害 FCFS 相对大约 0.11–0.15 | 方向还在，不升格 |
| 早时机 \(\rho_b=1\) | 服务噪声、到达抖动、三种混合下仍是 0 | 这是早时机几何，不是“任意时机都为 0” |
| 中时机 \(\rho_b=1\) | FCFS −0.049 且区间跨 0；PLAS −0.364；SRPT −0.302 | 精确零不能外推到中时机 |
| 功效 | 所需最大约 15，没有格子因功效被删 | 不把“样本够”写成“效应很大” |
| API 60 条 | 传输错误 0，旧提交 0。无害误撤 G1 10/10、G2 0/10。种子 9104 放槽早于停读 0.015 秒 | 事件链检查。两个任务同时在飞，秒数不进主表 |

种子级异质性留在论文第 5.1 节：中负载 FCFS、\(\rho_h=0.5\) 有 10/50 条差为 0；中负载 SRPT、\(\rho_h=2\) 有 9/50 条为负；PLAS、\(\rho_h=2\) 有 7/50 条为负。

## 6. 文献核对

2026-11-04。没有一篇把旁观者等待、撤销政策、\(\rho\) 和调度器放进同一个主实验。逐篇对照表在 [论文4.0.md](./论文4.0.md) 第 2 节，这里不重复。

核对时明确排除的主张：

- PlanFence 的 \(\rho\) 是更新强度。
- Retire 的指标是被替换任务自己的交接和 goodput。
- Agentix / Autellix 的 PLAS 是程序级调度。本文只借用“已完成服务越多越靠后”。
- Vesta 的外部影响发生在放置和 KV 传输，而且已经使用 queueing externality。

若以后出现同一主实验，改论文第 2 节和摘要，并在本节记下日期。

## 7. 复现

在仓库根目录。需要 Python 3.12+。

```powershell
python -m uv sync --extra dev
python -m uv run pytest -q
python -m uv run python scripts/analyze_v21.py
python -m uv run python scripts/plot_v21_figures.py
```

前两条确认测试和主表重算。后一条只从已有 JSON 重画三张 SVG，不需要 matplotlib。敏感性脚本是 `scripts/close_v21.py`，它写 `results/experiments/v4_0/`，不覆盖确认性 JSONL。没有核对主表的理由时不要跑它，一次大约一分钟以上。

`scripts/run_v21_pilot.py --phase confirmatory` 会删除并重写确认性。核对论文时禁止执行。

真实 API 检查只在 `.env` 里已有 `DEEPSEEK_API_KEY` 时才有意义。密钥不进仓库，不进日志，不进论文。没有密钥时，主结论仍然只来自回放。
