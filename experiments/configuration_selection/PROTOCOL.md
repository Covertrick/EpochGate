# Protocol: configuration selection under notification delivery

Frozen before execution. This is a bounded feasibility pilot under the research plan. Run acceptance first, then pilot only after acceptance passes. Create a new output directory for every run. The confirmatory and holdout gates are conditional.

## Treatments

Replay the existing mechanism_validation Direct, Admission and Claim path functions without changing them. Use their shared local SQLite receiver transaction through an in-process adapter. Deliver or drop an identical notice at the shared authority_gate hook after installing the same target state. The notification handler updates the local observed generation on receipt of a business change and marks local eligibility false on receipt of a real revocation. Target business truth and permission are separate. Direct receives the same notice and has no gate; Admission latches its request once; Claim records the observed authority and uses its durable local gate. There is no additional gate after claim. These are configuration comparisons.

The deterministic application attempts a frozen reservation, then records an order disposition after a conclusive result. The disposition is a separate workflow action under its own fixed authority, executed through the same configuration. It records whether the reservation request was accepted or withheld and does not overwrite the reservation. The terminal objective is a correctly linked order disposition, including a recognized refusal. A separate predetermined obligation to issue an acknowledgment is tested with the same disposition as a negative control. When applicable that acknowledgment is required after a withheld reservation; these configurations do not synthesize it. This is an application-level test contract, not evidence about an autonomous planner.

Acceptance covers one invalidating business change, one clean control and one true revocation. Pilot covers 16 matched proposal instances in five fixed scenario strata (invalidating, benign, obligation, revocation, clean). Instances reuse scenario templates and are not assumed to be independent draws from a population. Shuffle the six cells reproducibly. Read-only audit uses target DB rows, target world snapshots and independently serialized inputs, not the runtime verdict. Preserve target commits and attempted-but-rejected outcomes.

## Frozen decision policy

The illustrative deployment requires all assigned tasks to have a linked completed disposition, with zero observed violations for each added compliance criterion. This is a strict scenario policy, not an inferred production SLA. Unknown evidence is ineligible for a definite recommendation. No statistical equivalence threshold is claimed. Compare S0 (terminal), S1 (+ target permission), S2-Sem (+ reservation semantics), S2-Succ (+ applicable obligation) and S2 (+ both) on the same traces. Pareto costs are actual submit calls and durable claim records. Elapsed runtime is separately reported because this adapter is in-process and repeated fixture timings are unstable.

Primary effect comparison is Claim vs Admission on the binary event S1 pass and S2 fail, per assigned notice and by stratum. Report discordance, exact paired McNemar and notification difference of differences descriptively; do not derive population inference from the fixture grid. Decision output keeps exact cost ties distinct from incomparable Pareto candidates. Report candidates eliminated by each diagnosed violation.

G2 proceeds only if S1 to S2 changes a recommendation in the delivered/undelivered analysis, the change has a traceable target effect or obligation, and there is a decision-relevant increment for the primary Claim vs Admission contrast (qualification or preferred choice differs). Increment confined to Direct is a secondary result, not a reason to fund a larger Claim versus Admission study. Confirmation requires an independently motivated deployment policy, new workload instances and a power plan. Holdout must remain unused if G2 fails. Do not submit a full paper on pilot evidence alone.
