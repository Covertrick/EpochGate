# Git reference recovery evidence pilot

Question: after a missing response to a real Git ref update, can target-native evidence distinguish a completed action from a matching state produced by another writer, or from a completed action later reversed?

Use new isolated bare repositories and Git's actual conditional ref updates. Freeze four histories: original committed, other writer committed an identical update, original committed then was reverted, and original was never dispatched. The controller retains command success as ground truth but withholds the original response from all decision rules. Cross those histories with retained reflog, disabled reflog, and explicitly expired reflog; cross each with an operation marker enabled or disabled. The marker is a separate ref written in the same Git ref transaction. Cooperating writers use distinct operation IDs. Recovery reads only the target snapshot and whichever evidence is available.

Compare target snapshot equality, matching old/new reflog entries without operation identity, matching operation ID in the retained reflog, and the operation marker. Also use real Git transport reads with the marker namespace exposed or hidden through server configuration. The attribution-bearing checks only confirm history when positive evidence exists. Absence returns UNKNOWN. To inspect historical success independently of current goal completion, report both outcomes. Count false confirmations, missed historical completions and unknowns per method. No hosted service, power loss, concurrent ref transaction failure, uncooperative writers or LLM behavior is tested. Explicit expiry in isolated disposable repos is a controlled fault, not an estimate of real retention.

Pilot completion requires paired histories with identical target OIDs but different ground truth, and exact audit reconstruction. A paper direction needs more than these constructed traces: a second operational surface or an externally maintained replay workload, and a demonstrated difference in safe follow-up decisions against the strongest available native evidence. Functional observations alone do not establish novelty or submission readiness.
